LoFrayer — Scraping Obstacles Log
Technical Log • Infrastructure • March 2026

Project Overview
LoFrayer is an Israeli application that centralizes membership club benefits. The primary challenge involves data extraction from Isracard Benefits (React SPA, geo-blocked to Israel, Cloudflare protected) and CAL Store (MemCyco anti-bot protected).

Session 1: Isracard Obstacles & Solutions
Obstacle 1: Geo-Blocking
Issue: Page fails to load from non-Israeli IP addresses.

Solution: Deployed a Google Cloud VM in me-west1-a (Tel Aviv) with a native Israeli IP, running a Browserless Chrome Docker container.

Status: SOLVED ?

Obstacle 2: Broken Browserless /function Endpoint
Issue: Received "Unexpected end of JSON input" errors.

Solution: Switched from the /function endpoint to the /content endpoint, which correctly returns rendered HTML.

Status: SOLVED ?

Obstacle 3: Cloudflare Bot Detection (Core Issue)
Issue: HTML response contains only Cloudflare "Attention Required" error. Cloudflare identifies Datacenter IPs as bots.

Solution: Implementing a Residential Proxy via WebScraping.ai to bypass detection.

Status: IN PROGRESS ??

Obstacle 4: Lack of Direct API
Finding: Data is Server-Side Rendered (SSR) directly into the HTML. No hidden JSON API exists.

Conclusion: Full page rendering is mandatory.

Status: UNDERSTOOD ??

Session 2: CAL Store Obstacles (MemCyco)
Obstacle 11: MemCyco Obfuscated JS Challenge
Issue: Site returns obfuscated JS instead of product content to verify human presence.

Solution: Built a dedicated Node.js Proxy using Puppeteer to execute the JS challenge and return the final rendered HTML.

Status: SOLVED ?

Obstacle 12: Headless Detection
Issue: MemCyco detects standard Headless Chrome via technical fingerprints.

Solution: Integrated puppeteer-extra-plugin-stealth to mask automated browser signals.

Status: SOLVED ?

Obstacle 16: Bash Heredoc Corruption (The "!" Symbol)
Issue: Exclamation marks in JS strings triggered Bash history expansion errors during terminal deployment.

Solution: Used Python Heredocs to write JS files, bypassing Shell interference.

Status: SOLVED ?

Obstacle 18: Supabase Edge Function Timeout
Issue: Page loads exceeded the 30s default timeout, causing function crashes.

Solution: Increased timeout to 90s and implemented "Batch Processing" (fetching 2 pages at a time instead of 5) to reduce CPU load.

Status: SOLVED ?

Session 3: VM & Proxy Refinement (CAL)
Obstacle 20: Out of Memory (OOM) Crashes
Issue: Chrome failed to launch due to less than 50MB of available RAM.

Solution: Cleared temporary cache and configured a 512MB Swap File on the disk.

Status: SOLVED ?

Obstacle 21: Early Extraction (domcontentloaded)
Issue: HTML was captured before the MemCyco JS challenge finished executing.

Solution: Changed wait strategy to networkidle2 (waiting for network silence).

Status: SOLVED ?

Obstacle 22: MemCyco Two-Phase Navigation
Issue: A second redirect occurred after the initial load, causing "Execution context was destroyed" errors.

Solution: Implemented Promise.race to wait for the secondary navigation or a fixed timeout before capturing content.

Status: SOLVED ? (Successfully extracted 137 benefits from 5 pages).
